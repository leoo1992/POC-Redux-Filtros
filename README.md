# POC Redux — Filtros

Prova de conceito para praticar filtros de dados em uma interface React, com Redux para controlar critérios e estado de filtragem.

## Stack
- React 18
- Redux
- JavaScript
- Create React App

## Como executar

```bash
npm install
npm start
```

Acesse http://localhost:3000. Testes: `npm test`; build: `npm run build`.
